# 破甲提示词（本仓库不附带内容，只留位置）

`server.py` 支持在系统提示里注入一段额外的角色扮演提示词。相关配置：

| 环境变量 | 作用 |
|---|---|
| `ARMOR_PROMPT_ENABLED` | `0` 关闭注入；默认开启 |
| 文件位置 | 固定读 `prompts/infinite-gen-2.md`（可通过代码里的 `ARMOR_PROMPT_PATH` 改） |

## 为什么不附带这个文件

两个原因，都很实际：

1. **授权**：这类提示词通常是第三方作者写的，能不能再分发要看对方的许可，本仓库不替你决定
2. **内容要自己判断**：角色扮演的自由度开多大、说哪些话合适，是使用者自己的选择，不该由仓库默认替你开

## 怎么用

1. 自己准备一份提示词文本
2. 存成 `prompts/infinite-gen-2.md`（UTF-8）
3. 重启服务；改文件不用重启，代码会按修改时间自动重读

没有这个文件时，代码会安静跳过（`armor_prompt_text()` 返回空串），其余功能完全正常。

## 分档行为

`server.py` 会按联系人的类型（`agents.kind`）决定注入的边界说明：

- `independent`（独立型）：打完提示词后再加一段"边界"说明，保留"被认真追问要承认是 AI"这条
- `dependent`（依附型）：不加那段边界

这套分档在代码里，和具体提示词内容无关——你换任何提示词，分档逻辑都照旧生效。
